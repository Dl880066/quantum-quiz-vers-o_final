# Quantum Quiz - Versão

Este projeto é uma aplicação React moderna construída com **Vite**, **Tailwind CSS** e **Shadcn UI**.

## 🚀 Como Começar

Siga estas instruções para configurar e rodar o projeto local locally.

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

### Instalação

1. Clone o repositório (se ainda não o fez):
   ```bash
   git clone https://github.com/Dl880066/quantum-quiz_version.git
   cd quantum-quiz_version
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

### Execução

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
` mountain
```

O servidor será iniciado em standard `http://localhost:5173`.

## 🛠️ Configurações do VS Code

Este repositório já inclui configurações otimizadas para o **Visual Studio Code**:

- **Extensões Recomendadas**: Ao abrir o projeto, o VS Code sugerirá a instalação de extensões essenciais (ESLint, Prettier, Tailwind CSS).
- **Auto-formatação**: O projeto está configurado para formatar o código automaticamente ao salvar.
- **Depuração**: Inclui uma configuração de launch para depurar directly no Chrome.

## 📁 Estrutura de Pastas

- `src/api`: Integrações e calls de API.
- `src/components`: Componentes React reutilizáveis.
- `src/hooks`: Hooks customizados.
- `src/lib`: Utilitários e instâncias de bibliotecas.
- `src/pages`: Componentes de página (rotas).
